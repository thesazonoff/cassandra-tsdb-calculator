Диски и сеть подробнее
Медианная оценка для старта внедрения и проектной документации. Объём сверен с Apache Cassandra 5.0.9 на типовом профиле значений; на действующей инсталляции уточняется во вкладке «Калибровка». Версия 2.0.1 ·

Что нового в 2.0

  • Объём на диске считается по точному формату строк SSTable Cassandra 5.0.9 с учётом сжатия LZ4 16 КиБ. Модель сверена с официальным дистрибутивом 5.0.9: побайтно с SSTable, записанными кодом Cassandra, и с точностью 0,12 % на запущенном сервере.
  • Сравнение LZ4 и хранения без сжатия.
  • Калибровка по выводу nodetool tablestats с действующей инсталляции.
  • Встроен калькулятор отказоустойчивости: racks, несколько ДЦ, размещение реплик как в NetworkTopologyStrategy, интерактивная схема отказов, вероятность при случайных отказах.
  • Третий вариант схемы: доработка драйвера C# (Unset.Value вместо null).
  • Конфигурация драйвера C#, cassandra-rackdc.properties на каждую ноду.
  • Работает без интернета: Excel, ZIP и отчёт PDF формируются внутри страницы.
  • Меньше полей: профиль пользователей одним выбором, параметры для архитектора спрятаны в «Дополнительно».
  • 2.0.1: по итогам проверки на сервере 5.0.9 уточнён вариант с Unset.Value (маска колонок 2 байта), заголовок партиции формата nb, в cassandra.yaml добавлены storage_compatibility_mode: NONE и формат BTI.
