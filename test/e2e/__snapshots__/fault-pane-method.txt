ΣRF: сумма RF по всем DC keyspace, RFc: RF DC приложения.ONE / TWO / THREE = 1 / 2 / 3 любых реплик QUORUM, SERIAL = floor(ΣRF / 2) + 1 любых реплик ALL = все ΣRF реплик LOCAL_ONE = 1 реплика в DC приложения LOCAL_QUORUM, LOCAL_SERIAL = floor(RF_c / 2) + 1 в DC приложения EACH_QUORUM = floor(RF_d / 2) + 1 в каждом DC ANY (только запись) = 1 нода, допускается hint на координатореКонсистентностьЧтение гарантированно видит подтверждённую запись, если любое множество реплик записи пересекается с любым множеством реплик чтения. Для нескольких DC проверяется, можно ли выбрать wd и rd так, чтобы wd + rd ≤ RFd в каждом DC при выполнении обоих CL. Если можно, множества могут не пересечься. Без потери данных: подтверждённая запись гарантированно лежит на W репликах (W − 1), после репликации на ΣRF (ΣRF − 1).Размещение реплик и racksРеплики размещаются кодом, повторяющим NetworkTopologyStrategy.calculateNaturalReplicas 5.0.9: обход кольца по часовой стрелке, сначала по одной реплике в каждом новом rack; если racks меньше RF, допускается RF − число racks повторов rack, и они берутся из первых встреченных нод. Отказ t racks оценивается по максимуму реплик одного диапазона в t racks.Доля данных на нодеПри сбалансированных токенах доля rack ограничена: если racks ≥ RF, rack хранит не больше одной копии (каждый диапазон не чаще одного раза); если racks < RF, rack хранит от 1 до 1 + RF − racks копий. Доли нод выравниваются в этих границах (water-filling), сумма долей DC равна RF.racks 3/3/2, RF 3: ноды по 1/3, 1/3 и 1/2 данных racks 3/3/3, RF 3: все ноды по 1/3Раскладка токенов«Алгоритм allocate_tokens (приближение)»: токены DC равномерно по кольцу, ноды чередуются по racks. Настоящий алгоритм Cassandra отличается в деталях, поэтому смоделированные доли совпадают с реальными приблизительно. «Случайная»: токены случайные, как без allocate_tokens_for_local_replication_factor; при 16 vnodes разброс долей нод заметен. P: доля исходов, где недоступен хотя бы один диапазон; «доля недоступна»: средняя доля кольца, для которой операция не выполняется.ОграниченияОтказ означает недоступность ноды.
