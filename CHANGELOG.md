# История изменений

## 2.0.1, 2026-11-09
- Вариант с `Unset.Value` уточнён по проверке на сервере Cassandra 5.0.9: маска отсутствующих колонок 2 байта для числовых типов.
- Учтён заголовок партиции формата nb, который 5.0.9 пишет с `cassandra.yaml` по умолчанию.
- В генерируемый `cassandra.yaml` добавлены `storage_compatibility_mode: NONE` и формат SSTable BTI для нового кластера.

## 2.0, 2026-11-09
- Объём на диске по формату строк SSTable 5.0.9 со сжатием LZ4, сравнение с хранением без сжатия.
- Калибровка по `nodetool tablestats`.
- Встроен расчёт отказоустойчивости: стойки, несколько ДЦ, схема отказов, вероятность при случайных отказах.
- Третий вариант схемы: доработка драйвера C#.
- Конфигурация драйвера C# и `cassandra-rackdc.properties` на каждую ноду.
- Работа без интернета: Excel, архив конфигов и PDF формируются в странице.
- Упрощён ввод: профиль пользователей одним выбором, параметры для архитектора свёрнуты.

## 1.0, 2026-10-20
- Первая версия: сайзинг кластера по группам тегов, RF и consistency level, диски по ролям, фрагменты конфигурации.
