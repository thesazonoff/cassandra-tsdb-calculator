Калькулятор перестроен из исходников: расчёты и тексты не изменились, файл стал легче, код открыт под лицензией MIT.

## Что изменилось для пользователя

- Обе страницы работают в одном документе, без вложенных фреймов. Файл 305 КБ вместо 422 КБ, открывается быстрее: вторая страница создаётся при первом переходе на неё.
- Ссылку на расчёт можно вставить в адресную строку уже открытого калькулятора: он откроет нужную страницу без перезагрузки.
- Старые ссылки открываются: версии 2.0.x, 2.1.x и отдельного калькулятора отказоустойчивости.
- Вторая страница оформлена в общей палитре.
- На телефоне вкладка «Методика» второй страницы больше не прокручивается вбок.

## Что проверено

- 34 сценария обеих страниц дают те же цифры и тексты конфигурации, что 2.1.0.
- Тексты всех вкладок для расчёта по умолчанию совпадают с 2.1.0.
- Модель объёма повторно сверена с Apache Cassandra 5.0.9 стендом из репозитория: 23 набора SSTable, записанных кодом Cassandra, совпали побайтно; на запущенном сервере байт на точку отличается от модели не больше чем на 0,08 %.

## Для разработчиков

Исходники, тесты, сборка и стенд проверки на Cassandra теперь в репозитории. Устройство: [ARCHITECTURE.md](https://github.com/thesazonoff/cassandra-tsdb-calculator/blob/v2.2.0/ARCHITECTURE.md), выбор стека: [ADR 0001](https://github.com/thesazonoff/cassandra-tsdb-calculator/blob/v2.2.0/docs/adr/0001-stack.md). Файл этого релиза собран из исходников после всех проверок CI.

## Установка

1. Скачайте `cassandra-tsdb-calculator-2.2.0.html` из блока **Assets** ниже.
2. Откройте его в браузере (Chrome, Edge, Firefox, Яндекс Браузер).

Проверка целостности файла:

```bash
sha256sum -c SHA256SUMS.txt
```

```powershell
Get-FileHash .\cassandra-tsdb-calculator-2.2.0.html -Algorithm SHA256
```

Отличие от предварительной версии [2.2.0-rc.1](https://github.com/thesazonoff/cassandra-tsdb-calculator/releases/tag/v2.2.0-rc.1): только номер версии.
