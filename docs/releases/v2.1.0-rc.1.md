Предварительная версия из ветки `release/2.1`. Последний стабильный релиз остаётся [2.0.1](https://github.com/thesazonoff/cassandra-tsdb-calculator/releases/tag/v2.0.1).

## Что нового

Два калькулятора в одном файле, страницы переключаются вверху:

- **Системные требования.** Калькулятор 2.0.1 без изменений: ноды, железо, диски с учётом LZ4, отказоустойчивость кластера, конфигурация.
- **Отказоустойчивость.** Отдельный калькулятор отказоустойчивости Cassandra 5.0: до 5 DC со своим RF, racks разного размера, все consistency level, LWT, num_tokens, схема отказов, вероятность недоступности при случайных отказах, конфигурация драйвера.

Ссылка на расчёт запоминает открытую страницу. Ссылки версии 2.0.1 продолжают открываться.

## Установка

1. Скачайте `cassandra-tsdb-calculator-2.1.0-rc.1.html` из блока **Assets** ниже.
2. Откройте его в браузере. Сервер и интернет не нужны.

Проверка целостности файла:

```bash
sha256sum -c SHA256SUMS.txt
```

```powershell
Get-FileHash .\cassandra-tsdb-calculator-2.1.0-rc.1.html -Algorithm SHA256
```

Расчёт для Apache Cassandra 5.0.9 и JDK 17.
