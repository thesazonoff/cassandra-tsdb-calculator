Калькулятор системных требований Apache Cassandra 5.0 для хранения временных рядов MES. Один HTML-файл, работает в браузере без установки и интернета.

## Установка

1. Скачайте `cassandra-tsdb-calculator-2.0.1.html` из блока **Assets** ниже.
2. Откройте его в браузере (Chrome, Edge, Firefox, Яндекс Браузер).

Проверка целостности файла (необязательно):

```bash
sha256sum -c SHA256SUMS.txt
```

```powershell
Get-FileHash .\cassandra-tsdb-calculator-2.0.1.html -Algorithm SHA256
```

Хеш должен совпасть со строкой в `SHA256SUMS.txt`.

## Что нового в 2.0.1

### Исправлено
- Вариант с `Unset.Value`: маска отсутствующих колонок 2 байта для числовых типов. Уточнено по проверке на сервере Cassandra 5.0.9.
- Учтён заголовок партиции формата nb, который Cassandra 5.0.9 пишет с `cassandra.yaml` по умолчанию.

### Изменено
- В генерируемый `cassandra.yaml` для нового кластера добавлены `storage_compatibility_mode: NONE` и формат SSTable BTI.

## Основное в линейке 2.x

- Объём на диске по формату строк SSTable Cassandra 5.0.9 со сжатием LZ4 и сравнение с хранением без сжатия. Модель сверена с официальным дистрибутивом 5.0.9: побайтно и с отклонением до 0,12 % на запущенном сервере.
- Калибровка по выводу `nodetool tablestats` с действующей инсталляции.
- Отказоустойчивость: стойки, несколько ДЦ, интерактивная схема отказов, вероятность недоступности при случайных отказах.
- Три варианта схемы: текущая, рекомендации без доработки MES, доработка драйвера C#.
- Готовая конфигурация: `cassandra.yaml`, `ALTER TABLE`, подключение из C#, `cassandra-rackdc.properties`.
- Экспорт в PDF, Excel и архив конфигов без интернета.

## Совместимость

Расчёт для Apache Cassandra 5.0.9 и JDK 17.
