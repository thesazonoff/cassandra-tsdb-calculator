Два калькулятора Apache Cassandra 5.0 для MES в одном HTML-файле. Работает в браузере без установки и интернета.

## Что нового

Вверху переключаются две страницы:

- **Системные требования.** Калькулятор 2.0.1: число нод, ядра, RAM, диски каждой ноды с учётом сжатия LZ4, три варианта схемы, калибровка по `nodetool tablestats`, готовая конфигурация и экспорт.
- **Отказоустойчивость.** Сколько нод, стоек и ДЦ может отказать при выбранных RF и consistency level. До 5 ДЦ со своим RF, стойки разного размера, все consistency level Cassandra 5.0, LWT, `num_tokens`. Худший случай, отказ целого ДЦ, вероятность недоступности при случайных отказах, интерактивная схема отказов, конфигурация.

Также:
- ссылка на репозиторий GitHub в верхней панели;
- ссылка на расчёт открывает нужную страницу с теми же значениями, ссылки версии 2.0.1 продолжают работать.

Отличие от предварительной версии [2.1.0-rc.1](https://github.com/thesazonoff/cassandra-tsdb-calculator/releases/tag/v2.1.0-rc.1): добавлена ссылка на GitHub.

## Установка

1. Скачайте `cassandra-tsdb-calculator-2.1.0.html` из блока **Assets** ниже.
2. Откройте его в браузере (Chrome, Edge, Firefox, Яндекс Браузер).

Проверка целостности файла:

```bash
sha256sum -c SHA256SUMS.txt
```

```powershell
Get-FileHash .\cassandra-tsdb-calculator-2.1.0.html -Algorithm SHA256
```

Хеш должен совпасть со строкой в `SHA256SUMS.txt`.
